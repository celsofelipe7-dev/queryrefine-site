Privacy Policy

Last updated: April 10, 2026

Data Collection

We collect email addresses only for account synchronization and to enable Pro features. This data is used exclusively to authenticate your account and is never shared with or sold to third parties.

User Activity

We monitor interactions within the extension popup (e.g., toggling filters on or off) solely to trigger the appropriate filtering behavior in real time. This interaction data is processed locally in your browser and is never transmitted to our servers.

Website Content

We read Google search queries entered in your browser solely to programmatically append filtering operators (e.g., -site:pinterest.com) before the search is submitted. No search query data is stored, logged, or transmitted to any server. All processing happens entirely within your local browser session.

Compliance

This extension complies with the Chrome Web Store User Data Policy. We only request the minimum permissions necessary to perform filtering (access to google.com search URLs). We do not use data for purposes unrelated to the extension's core function, and we never sell user data to any third party.

Contact

If you have any questions about this Privacy Policy or your data, please open an issue on our GitHub repository or contact us through the Chrome Web Store support channel listed on the extension page.
